# arena-api

Static copy of the ArenaMod shop lists, served with GitHub Pages.

| Endpoint | File |
|---|---|
| `GET /api/ctaItems` | `api/ctaItems` |
| `GET /api/storeCosmeticItems` | `api/storeCosmeticItems` |

Base URL: `https://<user>.github.io/arena-api`

The files have no extension on purpose: the mod requests `<base URL>/api/ctaItems` exactly.
